# Паспорт проекта

## 1. Название проекта

Магазин обуви «Лапа» — приложение для онлайн-каталога и заказа обуви.

## 2. Проблема

У небольшого магазина обуви каталог хранится на бумаге и в Excel: клиент не может посмотреть товар и оформить заказ, а продавец путается в остатках по размерам.

## 3. Пользователи

- клиент магазина — выбирает товар, добавляет в корзину и оформляет заказ;
- продавец-консультант — ведёт каталог и остатки, обрабатывает заказы;
- администратор — управляет пользователями и правами.

## 4. Цель проекта

Дать клиенту возможность выбрать обувь и оформить заказ онлайн, а продавцу — видеть актуальные остатки по размерам.

## 5. Метрики успеха

- время оформления заказа — < 2 минут;
- клиент находит нужную пару через поиск и фильтры — за < 3 кликов;
- остатки обновляются сразу после оформления заказа, без ручного ввода;
- продавец меняет статус заказа — за < 1 минуты.

## 6. Границы (что НЕ делаем)

- не подключаем реальные платёжные шлюзы (оплата — учебный симулятор);
- нет мобильного приложения, только десктопное приложение;
- доставка курьером не моделируется — заказ выдаётся в магазине;
- не ведём складской учёт поставщиков и закупок.

## 7. Риски

- не успеем метрики к дедлайну → приоритизация: сначала каталог и заказ, метрики в конце;
- сложно придумать 30+ товаров → берём реальный ассортимент из открытых источников;
- сложные права доступа → сначала две роли (клиент и продавец), администратора добавляем в конце.
