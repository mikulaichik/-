Апорт

Приложение для приюта собак: каталог питомцев и онлайн-заявки на усыновление.

Описание

Будущий хозяин просматривает каталог собак, фильтрует их и подаёт заявку на усыновление. Волонтёр-куратор ведёт карточки собак и обрабатывает заявки, администратор управляет пользователями и правами.

Подробнее о проекте: паспорт проекта.

Технологии
Язык: C#
Среда разработки: Visual Studio
База данных: MySQL, работа с ней и проектирование в MySQL Workbench
Структура репозитория
docs/       документация проекта (паспорт, диаграммы, ТЗ)
Как запустить
Установите Visual Studio и MySQL Workbench.
Клонируйте репозиторий:
bash
   git clone <ссылка на репозиторий>
В MySQL Workbench выполните скрипты создания базы данных.
Откройте решение (.sln) в Visual Studio, укажите строку подключения к базе и запустите проект.
