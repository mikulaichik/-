# Магазин обуви «Лапа»



## Описание

Клиент просматривает каталог, ищет обувь по фильтрам (размер, цвет, цена) и оформляет заказ. Продавец-консультант ведёт каталог, остатки и статусы заказов, администратор управляет пользователями и правами.

Подробнее о проекте: [паспорт проекта](docs/passport.md).

## Технологии

- **Язык:** C#
- **Среда разработки:** Visual Studio
- **База данных:** MySQL, работа с ней и проектирование в MySQL Workbench

## Структура репозитория

docs/       документация проекта (паспорт, диаграммы, ТЗ)

## Как запустить

1. Установите Visual Studio и MySQL Workbench.
2. Клонируйте репозиторий:
   ```bash
   git clone <ссылка на репозиторий>
   ```
3. В MySQL Workbench выполните скрипты создания базы данных.
4. Откройте решение (`.sln`) в Visual Studio, укажите строку подключения к базе и запустите проект.
